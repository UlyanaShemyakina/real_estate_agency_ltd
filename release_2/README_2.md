How Much Is The…? — Release 2

Предобработка данных

Цель

Подготовить данные об объявлениях аренды квартир для дальнейшего анализа.

Выполненные действия

- Загружены исходные данные из CSV-файла.
- Удалён технический столбец Unnamed: 0.
- Оставлены объявления с ценой в рублях.
- Цена и общая площадь преобразованы в числовой формат.
- Рассчитана цена за квадратный метр.
- Созданы дополнительные признаки: количество комнат, этаж, расстояние до метро, лифты, балконы и бытовые удобства.
- Категориальные признаки закодированы числами.
- Обработаны пропуски.
- Названия столбцов переведены на английский язык в формате snake_case.

Результат

Получен набор данных из 23 344 объявлений и 46 столбцов без пропусков.

Файлы
- preprocessing.ipynb — ноутбук с этапами предобработки.
- preprocessing.html — HTML-отчёт.
- ../data_processed/final_data.csv — обработанный набор данных.
