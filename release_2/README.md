Релиз 2. Предобработка данных

Цель

Подготовить данные об объявлениях аренды квартир для дальнейшего анализа.

Выполненные действия

Загружены исходные данные из CSV-файла.

Удалён технический столбец Unnamed: 0.

Проверены пропуски и полные дубликаты.

Извлечена валюта из поля Цена.

Цена преобразована в числовой формат.

Для анализа оставлены объявления с ценой в рублях.

Из поля Площадь, м² извлечена общая площадь квартиры.

Рассчитана цена аренды за квадратный метр в месяц.

Значения цены за квадратный метр округлены до двух знаков после запятой.

Обработанные данные сохранены в data_processed/real_estate_processed.csv.

Результат

В обработанном наборе данных — 23 344 объявления и 28 столбцов. Полные дубликаты и пропуски в рассчитанном показателе Цена за м² отсутствуют.
