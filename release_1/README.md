How Much Is The…? — Release 1

Описание проекта

Проект посвящён исследованию объявлений об аренде недвижимости. Цель первого этапа — изучить данные, выявить особенности распределения цен и площадей, а также подготовить основу для дальнейшего анализа.

Данные

Исходный набор данных содержит 23 368 объявлений.

Для анализа цен в рублях использована выборка из 23 344 объявлений. Объявления с ценами в долларах и евро исключены из анализа рублёвых цен.

Проведённый анализ

Изучена структура данных.

Проверены пропущенные значения.

Исследовано распределение цен аренды.

Исследовано распределение общей площади квартир.

Изучена зависимость цены аренды от площади.

Построены графики и сформулированы предварительные выводы.

Основные результаты

Медианная цена аренды — 49 900 рублей в месяц.

Медианная цена аренды квадратного метра — 1 000 рублей в месяц.

Между площадью квартиры и стоимостью аренды наблюдается положительная связь.

В данных присутствуют пропуски и потенциально аномальные значения, требующие дальнейшей проверки.
